# Duplicate Purchase Prevention

DLsite / FANZA などで、既に保有している作品を誤って再び買う前に気づかせ、必要なら購入進行を止めるためのコンテキスト。

## Language

**介入対象店舗**:
第一波でページ介入と購入進行ブロックの対象とする店舗集合。DLsite、FANZA 同人、FANZA ブックス。
_Avoid_: 全店舗、対応済みストア（ライブラリ同期だけの店舗を含む呼び方）

**保有ライブラリ**:
ユーザーが同期・登録した、店舗ごとの保有 listing の集合。外部へ送らずローカルに置く。
_Avoid_: 購入履歴クラウド、アカウントライブラリ（店舗側 UI そのもの）

**確定重複**:
lookup の結果、同一サイト保有（`owned`）または他サイトの完全一致保有（`other`）と判定された状態。購入済み相当として扱う。
_Avoid_: 重複候補、possible、あいまい一致

**重複候補**:
同一メーカー想定かつ類似度が高いが、保有済みとは断定しない状態（`possible`）。購入済み表示にも購入進行ブロックにも使わない。
_Avoid_: 確定重複、購入済み

**購入進行ブロック**:
確定重複があるあいだ、ユーザーが支払完了へ進めないようにする既定動作。自動ではカートから消さない。
_Avoid_: 自動削除、購入禁止フラグ（店舗側の永続設定）、オーバーライド付き警告

**即購入**:
商品ページ上でカートを経由せず、購入手続きへ進む操作。
_Avoid_: カート投入、今すぐカゴへ

**カート投入**:
商品をカート（バスケット）に入れる操作。購入完了そのものではない。
_Avoid_: 即購入、注文確定

**購入進行面**:
カートを離れたあと、支払完了前までに購入を進める各ページ。内容確認・支払い手段選択・最終確定などを含む。
_Avoid_: サンクスページ、購入完了画面、カートページそのもの

**照会不能**:
サーバ未起動・通信失敗・照合結果なしなど、確定重複とも非重複とも言えない状態。このとき購入進行は止めない。
_Avoid_: 未保有、サーバエラー表示（購入面に出す前提の呼び方）
