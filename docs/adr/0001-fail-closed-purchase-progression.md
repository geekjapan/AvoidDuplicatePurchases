# 確定重複時は購入進行をブロックする（fail-closed）

重複購入防止の中核として、介入対象店舗では lookup が確定重複（同一サイト保有または他サイト完全一致）を返したとき、警告だけでなく購入進行自体を止める。自動削除はせず、カート内の重複をユーザーが消すか、保有ライブラリ上の事実を訂正するまで進めない。ギフトや意図的再購入のためのオーバーライドは持たない。

以前の承認スペックは商品・一覧・カートでの警告と手動削除に留まり、購入確認や即購入のブロックは定義していなかった。#57 の再現（一覧からカートへ入れたあと警告なく購入まで進める）と中核目的を踏まえ、警告のみでは不十分と判断した。

## Considered Options

- **警告のみ** — 現行スペック相当。購入は止められない
- **購入進行ブロック（採用）** — 確定重複中は即購入・カートからの進行・購入進行面を止める
- **ブロック + 明示オーバーライド** — 誤クリックで無効化されやすく、例外要求が具体化するまで不要
- **照会不能時もブロック** — ローカルサーバ未起動で日常購入が封じられ、結合が強すぎる

## Consequences

- カートに確定重複が1点でも残る間は、カート全体の購入進行を止める
- 商品ページは即購入のみ止め、カート投入は許す。一覧からのカート投入も止めない
- 重複候補（`possible`）と照会不能では止めない
- 介入対象は DLsite / FANZA 同人 / FANZA ブックスで同一契約
- `docs/spec.md` の介入節は本 ADR に合わせて更新が必要
